## 수집 결과와 범위

이 폴더는 문제 제작을 위한 참고 자료 모음입니다. 기업이 공개한 실제 기출문제, 출판사의 예상문제, 과거 예제, 시험 안내를 구분합니다. 현재 확보한 자료를 기업 공식 기출문제은행으로 표시해서는 안 됩니다.

- 원본 PDF 1개 다운로드: 해커스 GSAT 적중 예상 33제, 28쪽.
- 해당 PDF의 33개 문항에 대해 번호·유형·문제 위치·해설 위치 색인 생성.
- 공개 연습문제 사이트와 과거 예제 자료 링크 확보.
- 삼성·SK·LG·롯데·포스코·두산·현대 계열사의 공식 시험 안내 출처 확보.
- 웹앱에 원문을 재배포할 수 있다고 확인된 외부 문제는 현재 0개입니다. 참고자료 수집과 서비스 문제 DB 등록은 별도입니다.

## 4. 앱 개발에 적용할 분류 체계 — 자체 설계 제안

아래는 JOBFIT AI 내부 태그 제안이며 기업별 공식 분류표가 아닙니다.

| 영역 | 세부 태그 예시 |
| --- | --- |
| 언어 | 중심내용, 세부정보, 문장배열, 논증평가, 어휘관계 |
| 수리 | 비율, 증감률, 속력, 일률, 농도, 손익, 확률 |
| 추리 | 명제, 조건배치, 순서, 참거짓, 수열, 도형규칙, 도식변환 |
| 자료해석 | 표읽기, 그래프읽기, 비중, 가중평균, 역산, 복합비교 |

문제 데이터에는 `id`, `origin_type`, `source_url`, `rights_status`, `area`, `subtype`, `difficulty`, `answer`, `explanation`, `review_status`를 관리합니다. 기준 시간은 측정 근거를 확보하기 전까지 임시값임을 표시합니다.

## 5. 후속 작업 기준

1. 수집 자료의 유형을 참고해 자체 문제를 제작합니다. 원문의 숫자만 바꾸어 복제하지 않습니다.
2. 문항별 정답 유일성, 계산 결과, 해설, 도형 표시를 검토합니다.
3. 검토된 자체 문제와 사용 허가가 확인된 문제만 앱 시드 데이터로 등록합니다.
4. 기업별 모의 구성을 제공할 때는 공고 출처와 적용 시점을 함께 기록합니다.
5. `references/`의 외부 원본은 로컬 참고용으로 관리하고, 허가 확인 전 공개 GitHub·배포 자산에 포함하지 않습니다.
