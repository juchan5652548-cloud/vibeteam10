# (JOBFIT)

프로젝트를 시작하기 전에 [docs/SETUP.md](docs/SETUP.md)를 먼저 읽으세요.

## 프로젝트 개요
- 한 줄 소개: 취업 필기시험 대비를 위해 문제 풀이, 오답 복습, AI 힌트를 제공하는 학습 앱입니다
- 누구를 위한 앱인가: 대기업 인적성, 공기업 NCS, 병원 인적성 시험을 준비하는 취업 준비생을 위한 앱입니다.
- 어떤 상황에서 쓰는가: 지원 분야에 맞는 문제를 연습하거나, 틀린 문제를 복습하고 부족한 영역을 확인할 때 사용합니다.

## 주요 기능
| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. |	분야·영역·난이도·검색 필터, 문제 풀이, 정답과 해설 표시 | /api/practice/check에서 답안을 검증하고 서버 문제은행을 기준으로 채점|
| 2. | 	GitHub 로그인, 개인 오답노트, 북마크, 학습 통계| /api/auth, /api/account/progress에서 인증과 본인 기록 조회·저장 처리|
| 3. |	‘AI한테 물어보기’에서 추천 질문·직접 질문·추가 질문 제공 |/api/practice/hint에서 로그인과 사용 한도를 확인하고 Gemini API 호출 |

더 만든 기능:대기업·공기업·병원 분야별 300문항씩 총 900개의 자체 제작 연습문제
세 분야에서 총 6문항을 푸는 빠른 진단
무작위 최대 5문항 연습
선택한 보기별 피드백과 오답 재도전
게스트의 브라우저 학습 기록 저장
관리자용 회원별 학습 현황 조회·검색·정렬
모바일 화면 대응

## 기술 스택
- 프론트엔드:Next.js App Router, React, TypeScript, Tailwind CSS 및 일반 CSS
- 백엔드:Next.js Route Handler, Zod 입력 검증, Supabase Auth, Google Gemini API
- 데이터(어디에, 무엇을):
저장소의 JSON 파일: 문제·보기·정답·해설·보기별 피드백
Supabase PostgreSQL: 로그인 사용자의 풀이 기록과 북마크. RLS로 본인 자료 접근 제한
브라우저 localStorage: 게스트의 최근 풀이 기록과 북마크
Prisma 7: 기본 DB 연결 구성이 포함되어 있으며, 현재 개인 학습 기록은 Supabase Data API로 처리
## 실행 방법
<!-- 처음 보는 사람이 그대로 따라 할 수 있게 쓴다. 시작 저장소 그대로라면: npm install → npm run dev → 브라우저에서 http://localhost:3000 -->
1.Node.js 24와 npm을 준비하고, package.json이 있는 프로젝트 폴더에서 터미널을 엽니다.
2.다음 명령을 순서대로 실행합니다.
npm ci
npm run dev
3.1. 브라우저에서 http://localhost:3000을 엽니다. 다른 포트가 표시되면 터미널에 나온 주소를 사용합니다.
기본 문제 풀이 화면은 외부 서비스 설정 없이 실행할 수 있습니다. 로그인·계정 저장·AI 힌트를 사용하려면 .env.example을 참고해 .env.local에 다음 값을 설정해야 합니다.
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
- GITHUB_AUTH_ENABLED — Supabase의 GitHub 로그인 설정을 완료한 경우 true
- GEMINI_API_KEY
별도 Supabase 프로젝트를 사용할 경우 인증 제공자와 학습 기록 테이블·RLS 설정도 필요합니다. 자세한 내용은 [로그인 안내](docs/JOBFIT_AUTH.md)와 [AI 힌트 안내](docs/JOBFIT_AI_HINT.md)를 참고하세요.

배포 주소(있으면): [https://vibeteam10.vercel.app](https://vibeteam10.vercel.app)

배포 설정과 수정 반영 방법: [JOBFIT AI 배포 기록](docs/JOBFIT_DEPLOYMENT.md)

## AI 활용 내역
- 사용한 도구:Codex, Google Gemini API
- 주요 프롬프트(그대로 붙여 넣기):
- AI가 만든 것 / 사람이 고친 것:AI 활용: 화면·A문제은행 확대
대기업 인적성, 공기업 NCS, 병원 인적성 문제를 각 분야별 300문항씩, 총 900문항까지 추가해줘.
관리자 학습 현황 기능
관리자 모드를 추가해줘. 회원별로 문제를 얼마나 풀었는지, 얼마나 맞히고 틀렸는지 등 학습 현황을 확인하고 싶어.
관리자 권한 설정
지정한 GitHub 로그인 계정에만 관리자 권한을 부여해줘. 해당 계정으로 회원별 학습 현황을 확인할 수 있도록 해줘.
심사기준에 따른 개선
이전에 전달한 심사기준으로 현재 프로젝트를 평가해줘. 기준별로 부족한 부분을 확인하고, 필요한 수정과 검증까지 진행해줘.
기존 작업 이어서 진행
어제 진행했던 JOBFIT 문제은행 작업을 불러와줘. 기존 구현 내용과 진행 상태를 확인하고 이어서 작업할 수 있도록 준비해줘.I 구현, 문제은행 제작·확대, AI 힌트 연결, 검증 스크립트와 문서 작성
사람의 결정·검토: 서비스 방향, 기능 요구사항, 로그인 방식과 AI 서비스 선택, 화면·문제·답변 확인 및 수정 요청
- 결과를 확인한 방법:기능 개발 단계에서 타입·린트·포맷 검사와 프로덕션 빌드 수행
문제 데이터의 문항 수·정답 연결·중복·피드백 검사
900문항 확대 시 계산·순서·최적화 답안 500개를 별도로 계산해 비교
배포 사이트에서 기존·신규 문제의 정답·오답 제출 총 24건과 해설·피드백 확인
이전 기능 검증에서 GitHub 로그인, 기록 유지, 오답 복습, 실제 AI 응답 확인

## 아쉬운 점과 다음에 할 일
문제는 자체 제작 연습문제로, 전문가 검수와 실제 사용자 풀이 데이터를 통한 난이도 보정이 필요합니다.
일부 신규 문항은 같은 유형의 조건·수치 변형이므로 출제 유형을 더 다양하게 늘릴 계획입니다.
AI 힌트의 정확성과 정답 노출 방지에는 한계가 있어 답변 품질 검증을 보강해야 합니다.
AI 사용 제한을 여러 서버 인스턴스에서도 일관되게 적용하도록 개선할 예정입니다.
