# JOBFIT AI 무료 AI 힌트

## 현재 연결

문제별 ‘AI한테 물어보기’는 서버에서 Google Gemini API를 호출한다. 모델은 공식 요금표에서 무료 등급을 제공하는 `gemini-3.5-flash-lite`로 고정했다. 사용자 승인 후 기존 Google AI Studio 프로젝트의 ‘무료 등급’을 화면에서 확인하고 키를 Vercel Production `GEMINI_API_KEY` Secret으로 저장했다. 키 원문은 코드·문서·채팅에 기록하지 않았다.

[공식 요금표](https://ai.google.dev/gemini-api/docs/pricing) · [모델 안내](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite) · [API 명세](https://ai.google.dev/api/generate-content)

결제 계정·카드·유료 플랜은 연결하지 않았다. 무료는 무제한을 뜻하지 않는다. 실제 할당량은 [AI Studio 제한 화면](https://aistudio.google.com/rate-limit)에서 확인한다. 무료 한도를 초과하면 오류를 안내하고 기본 해설은 계속 이용할 수 있다. OpenAI나 다른 유료 모델로 자동 전환하지 않는다. 운영자가 나중에 같은 Google 프로젝트에 결제를 연결하면 요금 조건이 달라질 수 있으므로 연결 전에 앱 사용을 중지하고 별도 검토해야 한다.

## 사용 흐름과 데이터

로그인 → 문제 열기 → ‘AI한테 물어보기’ → 추천 질문 또는 직접 질문 → 현재 문제에 대한 짧은 풀이 방향 답변. 사용자의 계정 ID·이메일·전체 오답 기록은 모델에 보내지 않는다. 현재 문제의 영역·지문·질문과 최근 대화만 전송한다. 선택지 목록·서버 정답 키·해설은 전송하지 않는다. 사용자가 질문에 직접 적은 내용에는 선택지 내용이 포함될 수 있다.

무료 서비스의 질문·응답은 Google의 제품 개선에 사용될 수 있다. 화면에도 이 사실과 개인정보 입력 금지를 안내한다. 요청에 `store:false`를 적용하지만, 이것이 무료 서비스의 데이터 이용 조건을 없앤다는 의미는 아니다. [공식 서비스 조건](https://ai.google.dev/gemini-api/terms).

AI 출력은 정답·채용 합격·의료 판단을 보장하지 않는다. 채점과 기본 해설로 확인한다. 모델이 정답 노출 금지 지시를 항상 지킨다고 주장하지 않는다.

## 서버 보호와 제한

- Supabase로 서버 세션을 확인한 로그인 사용자만 호출한다.
- 같은 Origin·JSON 요청만 허용한다. 질문 1~300자, 최근 대화 최대 4개, 각 대화 1,800자, 본문 12KB 상한을 검사한다.
- 모델·호스트는 서버에 고정하고 키는 URL 대신 `x-goog-api-key` 헤더에 넣는다. 도구 호출·검색·외부 URL 접근 권한을 부여하지 않는다.
- 문제·질문·대화는 신뢰할 수 없는 데이터로 취급한다. 출력은 일반 텍스트로 렌더링하고 HTML로 실행하지 않는다.
- 공급자 요청은 전체 25초, 출력 최대 2,048토큰이다. 미완료·빈 답변·잘못된 응답은 성공 처리하지 않는다.
- 사용자당 10분 내 8회·동시 1개, 서버 인스턴스당 시간당 100회로 제한한다. 이는 메모리 기반이며 여러 인스턴스의 전체 사용량 상한은 아니다. 공급자의 무료 프로젝트 제한을 함께 적용한다.
- 공급자 오류·키·내부 상세를 화면이나 로그에 출력하지 않는다. 실패 시 질문을 유지하고 한도 안내를 제공한다.

## 설정

로컬은 Git에서 제외한 `.env.local`, 배포는 Vercel Production Secret에 `GEMINI_API_KEY`를 저장한다. 공개 변수 접두사는 붙이지 않는다. Preview에 운영 키를 복사하지 않는다. 키 등록 후 새 배포가 필요하다.

## 이전 OpenAI 연결

초기에 OpenAI 키를 등록했으나 크레딧이 없어 실제 답변을 검증하지 못했고 사용자가 충전을 보류했다. 이후 무료 실행 요청과 Gemini 전환 승인을 받아 현재 코드에서 OpenAI 호출을 제거했다. 기존 Vercel OpenAI 비밀값은 이 코드에서 사용하지 않으며 자격 증명 자체를 임의 폐기하지 않았다.

## 검증 상태

구조 검사와 공급자 호출 없는 오류 fixture, 실제 빌드·배포·브라우저 왕복 결과는 이번 작업이 완료되는 대로 아래에 기록한다. 키 등록 사실만으로 실제 응답 성공을 주장하지 않는다.

Node24의 타입·린트·포맷 검사와 프로덕션 빌드가 통과했다. `node scripts/check-ai-hints.mjs`에서 실제 모듈을 격리해 요청 계약·키 헤더·정답/계정정보 미전송·응답 처리·안전한 오류·동시/횟수 제한·입력 경계를 확인했다. 모든 응답은 fixture이며 실제 Gemini 호출은 하지 않았다.

### 첫 Production 왕복과 보완

소스 `75d6d46`, Vercel 배포 `HAsBhJHLFw9QkfpTs8oL8jVeeL4p`의 Production Ready를 확인했다. 로그인한 실제 브라우저에서 E024와 H030 질문에 `gemini-3.5-flash-lite` 응답을 받았다. 무료 프로젝트를 사용하며 결제·충전은 수행하지 않았다. 문제 전환 시 이전 대화가 초기화되는 것도 확인했다.

답변 검토에서 E024의 불필요한 유형명 언급과 H030의 특정 보기 지목이 관찰됐다. 이를 줄이기 위해 선택지 목록을 요청에서 제거하고, 지문 기반 개념·첫 검토 단계만 짧게 설명하도록 지시를 보완했다. fixture에 선택지 미전송 검사를 추가했고 check/build와 개선 후 실제 응답을 다시 확인한다. 사용자가 직접 적는 질문까지 정답 노출 없이 제어된다고 보장하지 않는다.

### 보완 후 Production 확인

소스 `993d478`, 배포 `8JS6jrJHBCEphdXNR8QmeZc8jven`의 Production Ready를 확인했다. `npm run check`, `npm run build`, 선택지 미전송을 포함한 AI fixture 검사가 통과했다. 실제 로그인한 계정의 H030 질문에서 선택지를 지목하지 않고 조건 분석·첫 대조 단계를 안내하는 한국어 답변과 모델명을 확인했다. 이는 관찰한 응답의 확인이며 모든 질문에서 모델 정확성·정답 미노출을 보장하지 않는다.

현재 이메일 회원가입은 별도 SMTP 연결이 남아 있지만 GitHub 로그인으로 AI 질문을 이용할 수 있다.

H030에서 후속 질문 ‘상태 유지와 다음 단계 이동은 어떻게 구분해?’에도 실제 답변을 받아, 같은 문제의 최근 대화를 이용한 추가 질문까지 확인했다. 채점 버튼은 누르지 않아 계정의 풀이 기록은 추가하지 않았다.
