# JOBFIT AI 실제 힌트 연결

OpenAI의 Responses API를 서버에서 호출한다. API 키는 사용자 로그인 수단이 아니며, GitHub 간편 로그인과 별도로 설정한다. ChatGPT 사이트 로그인(SIWC)은 현재 일부 상용 파트너 대상 제한 제공이므로 임의의 클라이언트 ID나 다른 앱의 자격 증명을 사용하지 않는다. [공식 SIWC 안내](https://developers.openai.com/siwc/website).

## 키 등록 상태

사용자 승인 후 OpenAI에서 `JOBFIT AI hints` 키를 생성했다. 만료는 30일, 권한은 Responses 생성에 필요한 Restricted 범위로 선택했다. 실제 값은 Vercel `vibeteam10` 프로젝트의 Production `OPENAI_API_KEY` Secret으로 저장했다. 값은 저장소·문서·채팅에 기록하지 않았다. 키 생성·복사 후 클립보드 내용을 비웠다. 만료 전 운영자가 교체해야 한다.

키 등록 자체가 모델 응답 성공이나 사용 가능한 크레딧을 보장하지 않는다. 크레딧 구매·자동 충전·과금 설정 변경은 수행하지 않았다.

현재 OpenAI Billing 화면에서 사용 가능한 API 크레딧이 없는 상태를 확인했다. 충전과 실제 응답 확인은 남아 있다. ChatGPT 구독이 API 결제 설정을 대신하는 것으로 안내하지 않는다.

## 처리와 제한

- 로그인한 사용자만 `/api/practice/hint`를 호출할 수 있다. 세션은 서버에서 Supabase Auth로 확인한다.
- 질문은 최대 300자, 이전 대화 최대 4개, 요청 본문 최대 12KB다. 다른 Origin의 요청을 거부한다.
- 서버 문제은행에서 현재 문제를 찾아 전송하며 정답 키는 보내지 않는다. 문제·질문·대화 기록은 신뢰할 수 없는 학습 데이터로 취급한다.
- 기본 모델은 `gpt-5.4-mini`, `store:false`, 출력 상한 700토큰, 공급자 요청 시간 제한 25초다. 정답 번호 대신 개념·첫 단계 중심 힌트를 요청한다.
- 응답은 일반 텍스트로만 화면에 출력한다. 모델은 틀릴 수 있으므로 채점 후 문제 해설을 함께 확인한다.
- 사용자당 10분 내 8회, 동시 요청 1개, 인스턴스당 시간당 100회 제한을 둔다. 메모리 기반 제한은 여러 인스턴스의 전체 사용료 상한이 아니다. 공개 운영 시 분산 제한과 공급자 예산 설정이 필요하다.
- 오류 시 키·내부 응답 대신 안전한 메시지를 보여주며 질문을 유지한다. 공급자 인증·크레딧 한도·지연은 실제 호출로 별도 확인해야 한다.

## 현재 검증 범위

타입·린트·포맷·프로덕션 빌드가 통과했다. HTTP 경계 검사에서 비로그인 AI 호출 차단과 GitHub 제공자 준비 전 차단을 확인했다. AI 로그인 경계 검사는 로컬 서버 프로세스에 가짜 테스트 키를 설정해 진행했으며 OpenAI에 요청하거나 실제 사용료를 발생시키지 않았다. Production에서는 키 설정 여부가 준비됨으로 표시되는 것을 확인했다. 실제 GitHub 로그인·로그아웃과 계정 오답 저장은 검증했으며 자세한 기록은 [로그인 검증](JOBFIT_AUTH.md#production-확인)에 있다. 키 등록 사실과 실제 AI 응답 성공은 구분한다. 사용자가 충전을 보류했으므로 실제 AI 힌트 왕복은 아직 검증하지 않았다.
