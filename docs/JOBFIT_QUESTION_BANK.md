# JOBFIT AI 문제은행

## 구성

- 대기업 인적성 12문항: 응용수리, 자료해석, 추리, 언어.
- 공기업 NCS 12문항: 의사소통, 수리, 자료해석, 문제해결, 자원관리, 정보, 대인관계, 직업윤리, 조직이해.
- 병원 인적성 12문항: 비임상 업무 상황의 의사소통, 수리, 자원관리, 문제해결, 정보, 대인관계, 직업윤리.
- 전 문항은 자체 제작 연습문제이며 실제 기출·복원·공식 문제가 아니다. 난이도는 임시 분류다. 조사 출처는 `research/aptitude/`에 있다.

## 사용 흐름

대시보드 → 지원 분야 선택 → 영역·난이도·검색 필터 → 개별 또는 무작위 최대 5문항 연습 → 답안 제출 → 서버 채점·해설 → 학습 결과 → 오답 복습.

빠른 진단은 각 분야에서 2개씩 총 6문항을 섞는다. 북마크, 최근 500회 풀이, 풀이 시간, 영역별 정답률은 현재 브라우저에 저장한다. 마지막 풀이에서 정답을 맞힌 문제는 오답노트에서 해결된다. 학습 분석은 정답률 기반 요약이며 합격 가능성 예측이나 AI 분석이 아니다.

정답 데이터는 초기 화면의 클라이언트 전달 데이터에서 제외하지만, 학습용 채점 API는 제출한 문제의 정답과 해설을 공개한다. 공개 GitHub 저장소에서도 자체 연습문제 정답을 볼 수 있다. 시험 보안 시스템으로 사용하지 않는다.

## 2026-10-29 로컬 검증

- Node.js 24에서 타입·린트·포맷 검사와 프로덕션 빌드 확인.
- 프로덕션 빌드를 포트 3100에서 실행.
- 36문항 × 보기 4개 = 144개 채점 요청에서 정답 판정과 정답 ID 일치 확인. 이는 채점 연결 검증이며 출제 내용의 전문가 검수를 대체하지 않는다.
- 잘못된 보기 400, 없는 문제 404, 잘못된 JSON 400, 2,049바이트 요청 413, 다른 Origin 403 확인.
- 초기 HTML에 `answerId`, `answer_id` 필드가 없는 것 확인.
- API 키 미등록 상태의 AI 질문 요청은 503 / `AI_NOT_CONFIGURED`. 실제 AI 답변은 아직 검증하지 않음.
- 브라우저에서 분야별 문항 수 12개, 대기업 문제의 오답·정답 채점과 해설, 결과 화면, 오답 해결, 학습 통계 반영 확인.
- 새로고침 후 북마크와 풀이 완료 표시 유지 확인.
- 모바일 너비 약 390px에서 병원 파트 화면 확인. 문서 가로 너비와 스크롤 너비 일치(375px).

## 대회 기준에서 남은 작업

로그인·계정별 자료 접근 제어·기기 간 기록 동기화는 미구현이다. 현재 게스트 기록을 로그인 기능처럼 채점할 수 없다. AI 질문은 사용자의 요청에 따라 API 키 연결을 뒤로 미뤘으며 실제 연결 전에는 AI 기능 완성으로 볼 수 없다. AI 제한은 서버 인스턴스 메모리 기준이므로 운영 시 분산 제한과 공급자 예산 제한이 필요하다.

로그인 후 화면 속도 측정, 다중 사용자 부하 시험, 실제 AI 응답 검증과 공격 입력 검증도 별도로 필요하다. 본 문서의 검증 범위를 넘는 대회 점수를 주장하지 않는다.
