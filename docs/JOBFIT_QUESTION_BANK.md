# JOBFIT AI 문제은행

## 구성

- 대기업 인적성 300문항: 응용수리, 자료해석, 추리, 언어.
- 공기업 NCS 300문항: 의사소통, 수리, 자료해석, 문제해결, 자원관리, 정보, 대인관계, 직업윤리, 조직이해.
- 병원 인적성 300문항: 비임상 업무 상황의 의사소통, 수리, 자료해석, 자원관리, 문제해결, 정보, 대인관계, 직업윤리, 조직이해.
- 전 문항은 자체 제작 연습문제이며 실제 기출·복원·공식 문제가 아니다. 난이도는 임시 분류다. 조사 출처는 `research/aptitude/`에 있다.

## 사용 흐름

대시보드 → 지원 분야 선택 → 영역·난이도·검색 필터 → 개별 또는 무작위 최대 5문항 연습 → 답안 제출 → 서버 채점·해설 → 학습 결과 → 오답 복습.

빠른 진단은 각 분야에서 2개씩 총 6문항을 섞는다. 게스트의 북마크·최근 500회 풀이·풀이 시간은 현재 브라우저에 저장하고, 로그인하면 Supabase의 본인 계정에 저장한다. 영역별 정답률은 해당 기록에서 계산한다. 마지막 풀이에서 정답을 맞힌 문제는 오답노트에서 해결된다. 학습 분석은 정답률 기반 요약이며 합격 가능성 예측이나 AI 분석이 아니다.

## 대회 기준에서 남은 작업

로그인·계정별 오답 기록 연결의 후속 구현과 검증 범위는 [로그인 안내](JOBFIT_AUTH.md)에 기록한다. AI 키 등록과 실제 응답 검증 상태는 [AI 힌트 연결 안내](JOBFIT_AI_HINT.md)를 확인한다. AI 제한은 서버 인스턴스 메모리 기준이므로 운영 시 분산 제한과 공급자 예산 제한이 필요하다.

로그인 후 화면 속도 측정, 다중 사용자 부하 시험, 실제 AI 응답 검증과 공격 입력 검증도 별도로 필요하다. 본 문서의 검증 범위를 넘는 대회 점수를 주장하지 않는다.
